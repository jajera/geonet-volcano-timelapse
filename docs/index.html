How this works
GeoNet stores volcano webcam stills (JPEG every ~10 minutes) in the public geonet-open-data bucket — not video files. This page shows each camera’s latest still; pick one to load that day’s frames as a browser timelapse. No ffmpeg or player install needed. Optional: download the day folder with AWS CLI, then load the local folder here to play offline.
