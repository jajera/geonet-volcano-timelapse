How this works
GeoNet stores volcano webcam stills (JPEG every ~10 minutes) in the public geonet-open-data bucket — not video files. This page lists a station/day, loads those frames, and plays them as a simple browser timelapse. No ffmpeg or player install needed. Optional: download the day folder with AWS CLI, then load the local folder here to play offline.
